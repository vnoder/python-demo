# 订单结算示例

这是用于代码审查练习的独立结算模块，使用 Python 标准库，无需安装依赖。

## 业务约定

- 金额以整数分表示；商品价格和数量为正整数。
- 商品小计等于每项单价乘以数量后求和。
- 固定优惠金额从商品小计中扣除，不能小于零或超过商品小计。
- 按折后商品金额判断免邮：达到 10,000 分（含）免邮，否则运费为 500 分。
- 应付金额为折后商品金额加运费。
- 空购物车应拒绝报价。

## 运行测试

从仓库根目录执行：

```bash
python3 -m unittest discover -s review_sandbox -p 'test_*.py' -v
```

测试覆盖正常报价、商品数量、折扣、免邮边界，以及输入校验。
